# Application Icons

## Required Icons

### app.ico
- **Size**: 256x256 pixels (multi-resolution .ico file recommended)
- **Format**: ICO file
- **Usage**: System tray icon and application icon
- **Current Status**: Using auto-generated default icon

## Creating Your Icon

You can create or convert an icon using:
- Online tools: https://www.favicon-generator.org/
- GIMP (with ICO plugin)
- Photoshop
- IconWorkshop

## Default Behavior

If `app.ico` is not found, the application will automatically generate a simple blue circle as the tray icon.

To use a custom icon:
1. Create or download an icon file
2. Name it `app.ico`
3. Place it in this directory
4. Rebuild the application
